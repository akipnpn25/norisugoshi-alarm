# のりすごしアラーム

電車内で仮眠するときに、目的地の到着予定時刻から起床時刻を逆算するアラームアプリです。

## 現在の位置づけ

このリポジトリは、一般公開するWeb・PWA版です。
自分専用のiPhoneネイティブ版は、別プロジェクトとして開発予定です。

## 重要な制限

このWeb版はブラウザ内のタイマーを使用しています。

端末のロック、スリープ、バックグラウンド移動、アプリを閉じる操作などにより、予定時刻にアラームが鳴らない場合があります。利用中は画面を開いたままにしてください。

## 主な機能

- 目的地と到着予定時刻の設定
- 3分前・5分前・10分前の起床設定
- 日付をまたぐ時刻計算
- 起床までの残り時間表示
- イヤホン接続確認と試し音
- アラーム履歴
- 再読み込み後のアラーム復元

## 使用技術

Next.js、React、TypeScript、Tailwind CSS、Supabase、Web Audio API

## 起動方法

npm install

npm run dev

## ビルド

npm run build
